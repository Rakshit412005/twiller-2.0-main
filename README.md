## About the Project

A full-stack social networking web application focused on real-time user interaction, 
built with a secure, scalable architecture supporting authentication, role-based access, 
and rich content workflows.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Auth:** Firebase Authentication, Google OAuth, OTP-based login
- **Media & Payments:** Cloudinary, Razorpay

## Features

- **Secure Authentication & Access Control**
  - OTP-based login and Google OAuth via Firebase
  - Role-based access control (RBAC)
  - Device tracking, login history monitoring, and browser-based access control

- **Scalable Backend APIs**
  - RESTful APIs built with Express.js for content interaction workflows

- **Multilingual UI Support**
  - Localized interface for multiple languages

- **Multimedia Uploads**
  - Media handling and storage via Cloudinary

- **Browser Notifications**
  - Real-time in-browser notification system

- **Subscription Plans & Payments**
  - Integrated payment processing using Razorpay
